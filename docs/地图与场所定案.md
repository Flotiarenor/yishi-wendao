## 一、第一原则

1. ✅ **时间是唯一推进维度，统一到息**（整数）。世界、战斗、移动共享同一条时间轴。
2. ✅ **空间是连续坐标**；**"格"不是设计概念**，只作为**局部、按需、可丢弃**的采样 / 寻路加速结构（玩家无感）。
   **精度与内存解耦**：全局只物化稀疏特征（河 / 路 / 城 / 灵脉），**地形一律按需采样**——
   采样密度由用途决定（显示 / 寻路 / 城内各选各的），互不牵连。见 §3.5。
3. ✅ **地图 = 代价场**；**路网 = 代价场里的低代价带**；**寻路 = 代价场上的 A\***。
   所有寻路需求（最快 / 避开大路 / 避开障碍 / 越野 / 飞行）都通过"改代价场"实现，一套算法通吃。
4. ✅ **地形不是墙，是代价**。除少数硬阻挡外，地形"能走但贵"。
5. ✅ **存档只存差异**：`world_seed` + 变化。地形 / 路网 / 城镇布局都是**纯函数重建**。
6. ✅ **皮骨分离**：玩家看到古风单位（时辰 / 里 / 丈），系统算整数息与浮点里。
7. ✅ **大地图的价值在距离 / 地形 / 路径 / 版图，不在内容量**——地形稠密、内容稀疏。

## 二、时间刻度

### 2.1 单位表（1 息 = 2 秒，沿用 `engine/settings.py` 既有口径）

| 单位 | 换算 | = 息 | 用途 |
|---|---|---|---|
| **息** | 原子单位 | 1 | 战斗、移动的底层刻度 |
| 刻 | 15 分 | 450 | 短动作显示 |
| **时辰** | 8 刻 = 2 小时 | 3 600 | 世界移动、昼夜、五行威力 |
| 日 | 12 时辰 = 96 刻 | 43 200 | 闭关、经济 tick |
| 月 | 30 日 | 1 296 000 | 势力演化 tick |
| 年 | 12 月 = 360 日 | 15 552 000 | 寿元 |

- ✅ 内部**只存一个整数 `t`（息）**；日 / 月 / 年 / 时辰都是派生显示。
- ✅ **显示策略**：主显古风（「第三日 · 午时」），括号给现代换算（「约 3.5 日」）。
  玩家永远看不到"息"，但他每个决定都精确消耗它。

### 2.2 昼夜与五行（接 `设计定案.md` §六 威力层）

| 时段 | 时辰 | 五行倾向 |
|---|---|---|
| 平旦 | 寅 卯 辰 | 木 ↑ |
| 日中 | 巳 午 未 | 火 ↑（**午时最盛**） |
| 日入 | 申 酉 戌 | 金 ↑ |
| 夜半 | 亥 子 丑 | 水 ↑ |

- ✅ **土旺四季**：辰 / 未 / 戌 / 丑 四个时辰额外叠加**土**加成（与传统"四季末十八日属土"同源）。
- ✅ 威力层最终 = **所在地五行浓度（地形 + 区域叠加）× 时辰倾向 × 技能五行克制**。
- 完成判据：修火系要真去火山、且**挑午时**——时辰不再是纯叙事。

## 三、空间模型

### 3.1 世界尺度

| 项 | 值 |
|---|---|
| 世界跨度 | **20 000 里见方** |
| 域数 | **25（5×5）**，每域 4 000 里 |
| 坐标 | `(x, y)` float64，单位**里**，原点西南角 |
| 精度 | 跨度 20 000 里、需 5 米精度 ≈ 10⁻⁵ 里 → float64 余量充足 |

**赶路时间表**（越野 22 里/日、官道 44 里/日、飞行 250 里/日）：

| 行程 | 距离 | 越野 | 官道 | 飞行 |
|---|---|---|---|---|
| 域内横穿 | 4 000 里 | 182 日 | 91 日 | 16 日 |
| **域内折返** | 8 000 里 | **364 日 ≈ 1.0 年** | 182 日 | 32 日 |
| **全图横穿** | 20 000 里 | **909 日 ≈ 2.5 年** | 455 日 ≈ 1.3 年 | 80 日 |

> 设计意图：**前期一个域就是整个世界**（域内折返要一年）；后期飞行把跨域压到数十日——
> **地图随境界"变小"是修仙体验的一部分，不做补偿**，靠"开新域 / 新界"提供新的空间感。

### 3.2 三档尺度（规则与渲染的分档，不是坐标系的分层）

| 档 | 空间尺度 | 时间结算 | 交互 | 视野 |
|---|---|---|---|---|
| **世界** | 里 ~ 百里 | 按息（显示为时辰 / 日） | 选目的地寻路 / 手动探路 | 神识半径 |
| **地点**（城镇·宗门） | 丈 ~ 里 | **按动作** | 点设施 | 全可见 |
| **秘境** | 丈 | 按息 | 逐段探索 | 小半径 + 迷雾 |

- ✅ **坐标空间只有一个、且连续**：进入地点 / 秘境是**相机推进 + 规则档位切换**，
  视觉上无缝缩放（`(1,1)` 的城镇放大后能看见 `(0.85, 0.21)` 的店铺），机制上仍是清晰档位。
- ✅ **空间无缝、规则分档**——这是本定案与"纯场景栈"方案的关键区别。
- ⚠️ 必须提供**当前档位 / 当前位置提示**，防止玩家在缩放中迷失层级。

### 3.3 地形集（12 种 + 4 类硬阻挡）

| 地形 | 越野速度（里/日） | 主五行 | 特性 |
|---|---|---|---|
| 官道 | 44 | — | 驿站、商队、**盘查（暴露）** |
| 小径 | 33 | — | 路况未知 |
| 平原 | 22 | 土 | 越野基线 |
| 草原 | 22 | 木 | |
| 林地 | 17 | 木 | **遮蔽视野，利于甩脱** |
| 丘陵 | 14 | 土 | |
| 沙漠 | 11 | 火 | 缺水 |
| 山地 | 8 | 土·金 | 需轻身术 |
| 峡谷 | 7 | 土·金 | 通道型，易设伏 |
| 沼泽 | 6 | 水 | 泥泞 |
| 雪原 | 6 | 水·金 | 天候恶劣 |
| 火山熔岩 | 4 | 火 | 高温 |
| **硬阻挡** | 0 | — | 深海 / 绝壁 / 禁制 / 虚空 |

- ✅ **地形主属性映射 + 区域叠加**：地形给主五行，域 / 灵脉级修正叠加其上（如"火山域"全境火浓度高）。
- ✅ 速度值为**占位数值**，可标定；**形状**（路 > 平原 > 林 > 山 > 水）为定案。
- ✅ 水域前期是硬阻挡，筑基后可渡、金丹后可飞越——**能力解锁改变通行性**。

### 3.4 生成（确定性、惰性）

1. **地形**：多倍频噪声（高程 / 湿度 / 温度）→ 阈值切分 → 山脉、水系、荒漠自然成带。
2. **水系**：高程下降路径 → 河流；低洼 → 湖泊。
3. **灵脉 / 矿脉**：按规则撒点（山中、水脉交汇、地脉节点）。
4. **城镇选址**：沿河、山口、平原交界。
5. **路网**：城镇间**最小代价路径**连接 → 路自然沿河谷、绕山口（不手工画路）。

### 3.5 精度分层与物化策略（2026-09-10 修订：本条是"格子化"争议的定论）

**原则：全局只物化稀疏特征，地形一律按需采样；采样密度是"每次查询的参数"，不是全局常量。**

| 层 | 物化方式 | 分辨率 | 存储 |
|---|---|---|---|
| **地形 / 高程 / 五行** | **纯函数按需采样**（多倍频噪声） | 调用方指定（0.1 里 ~ 100 里） | **零** |
| 河流 / 路网 / 城镇 / 灵脉 / 内容点 | 一次性确定性生成 | 世界级**稀疏**特征 | 稀疏数组 / 点集 |
| 寻路代价场 | **按查询窗口惰性生成**，用完即弃 | 窗口内自定步长 | 临时 |

**实测成本**（2026-09-10 本机）：

| 操作 | 耗时 |
|---|---|
| 单点 `fbm` 采样（4 个场合计） | **≈ 3.3 µs** |
| 100 里见方窗口 @ 1 里 | 0.11 s |
| 200 里见方窗口 @ 1 里 | 0.42 s |
| 1000 里见方窗口 @ 5 里 | 0.42 s |
| float64 在 20 000 里量级的绝对精度 | ≈ 2 纳米 |

**分辨率数量级**（全局物化 vs 局部按需）：

| 分辨率 | 全局物化 | 局部按需 |
|---|---|---|
| 100 里/格 | 4 万格 | — |
| 25 里/格 | 64 万格 | 可行 |
| 10 里/格 | 400 万格 | 可行 |
| **1 里/格** | **4 亿格 ❌ 不可行** | **0.42 s / 200 里见方 ✅** |

- ✅ **禁止**"全图预生成高精度地形数组"（4 亿格不可行）——这是**唯一被排除**的做法。
- ✅ **允许**"局部高精度窗口"：玩家所在区域 / 当前渲染视口 / 一次寻路的搜索窗，各按需生成、可缓存、可丢弃。
- ⚠️ 全局特征（河 / 路 / 城 / 灵脉）仍按**中等栅格**一次性生成——它们本就稀疏；**地形查询与它们的"格"解耦**。
- ⚠️ **视野半径必须 ≥ 全局特征栅格宽度**，否则迷雾揭示退化为"整格翻转"（见 §5）。
- ✅ **精度不是瓶颈**：从大陆到一张床全在同一套连续坐标里（`(10000.0, 10000.0)` → `(10000.12504, 10000.07316)` ≈ 2 厘米），
  float64 余量约 10⁷ 倍。

## 四、移动

### 4.1 代价场

```
移动耗时 = 路径积分 ∫ (1 / 有效速度) ds
有效速度 = 地形速度 × 境界系数 × (1 + 身法加成)
```

| 境界系数（占位） | 练气 | 筑基 | 金丹 | 元婴 | 化神 |
|---|---|---|---|---|---|
| 倍数 | 1.0 | 1.5 | 2.5 | 4.0 | 6.0 |

### 4.2 两种移动模式

| 地图状态 | 移动方式 |
|---|---|
| **有舆图** | 自动寻路：给**候选路径** + 过滤器 |
| **无舆图** | **手动探路**：直线推进，遇硬阻挡**停下等玩家决定方向**（手动绕行，**不自动寻路**） |

- ✅ **候选路径**（默认给 2–3 条，每条显示 耗时 / 风险 / 暴露 / 地形构成）：

| 候选 | 特点 | 谁会选 |
|---|---|---|
| 最快 | 时间最少，可能穿险地 | 赶时间 |
| 最安全 | 避开已知危险点，可能绕远 | 揣着重宝 |
| 最隐蔽 | 避开大路 / 人烟，暴露最低 | 被追杀 / 怕盘查 |

- ✅ **过滤器**（改变候选集，实时刷新对比）：避开大路 / 避开小径 / 避开障碍地形。
- ✅ **不设随机"迷路"机制**——玩家手动绕行时自然承担代价，不再额外掷骰惩罚。
- ✅ **长途分段**：移动按段结算，每段可触发事件、可中断改道（避免"40 天一次结算，中间什么都没发生"）。

### 4.3 飞行

- ✅ 门槛：**金丹**起可飞（练气 / 筑基只能走 + 渡水）。
- ✅ 速度：**250 里/日**（不受地形影响，只算直线距离）。
- ✅ 代价：耗灵气 / 灵石（灵舟）；**禁空区 / 禁制无法降落**；空中风险（妖兽 / 天候 / 禁制）。
- ✅ **飞行不暴露宝光**（高空拉开神识距离）；**低空掠过城镇 / 人群**才引人注意（被认出 / 被跟踪 / 强者神识扫到）。
- 🔧 飞剑 / 灵舟等装备作为加成来源（与功法 / 装备系统接）。

## 五、迷雾与情报

- ✅ **两层迷雾**：

| 层 | 内容 | 可见性 |
|---|---|---|
| **舆图** | 山川大势、域界、城镇方位 | **开局即有**（修仙界有舆图） |
| **实地** | 矿脉、灵草、兽巢、遗迹、秘境入口、小径、驿站 | **未知**，需揭示 |

- ✅ **揭示方式**：神识半径（随境界）、亲自踏勘、买地图、问人（接 P7 NPC）、飞舟俯瞰。
- ⚠️ **神识半径必须 ≥ 全局特征栅格宽度**（当前 100 里）：练气期半径若小于格宽，揭示会退化为"整格翻转"，
  迷雾就失去"逐渐看清"的观感。**基准建议**：练气 150 里（≈1.5 格）→ 筑基 300 → 金丹 600 → 元婴 1200 → 化神 2500；
  地形遮蔽（山地 / 林地）按倍率缩减，但缩减后仍 ≥ 1 格宽。
- ✅ **情报是资源**，可买卖——"信息不对称"原则的直接兑现。
- ✅ **地图分三档**：无舆图 / 粗舆图（买到 / 听说，路况未知）/ 详图（亲自走过或买精品）。
- ✅ **不做逐格探索度位图**：舆图已给地形，"探索"揭示的是**内容点**（有限集合），不是面。

## 六、城镇与场所

### 6.1 城镇呈现与城内坐标

- ✅ 城镇占世界层**一个地点**；进入 = 相机推进到**地点档**，放大为六边形底图 + **设施图标按局部坐标摆放**。
- ✅ **城内不是第二套坐标系**：设施坐标 = **世界坐标的小数部分**（1 里 = 500 m）：

| 层级 | 世界坐标 | 实际距离 |
|---|---|---|
| 镇中心 | `(10000.0, 10000.0)` | 0 |
| 镇内坊市 | `(10000.120, 10000.070)` | 0.12 里 = **60 米** |
| 一间客栈 | `(10000.1250, 10000.0732)` | 0.005 里 = **2.5 米** |

  float64 在 10⁴ 量级的绝对精度 ≈ 1 纳米 → **从大陆到一张床共用一套坐标，不存在精度不足**。
- ✅ 点设施 → 打开既有面板（坊市 UI 已有）；**无寻路、无视野**需求。
- 🔧 **预留"城内小图"扩展位**：城内 = 世界坐标里 1 里见方的一块，可逐格 / 连续移动、NPC 走动、跟踪 / 偷窃；
  **数据模型先留字段与接口**（仍是同一坐标系，只是采样更密）。
- ❌ 不做"城内独立坐标系 + 场景切换"；❌ 不做"六边形内几何嵌套"（多边形填充 / 点在多边形内判定）。

### 6.2 第一版设施（v1）

| 设施 | 功能 |
|---|---|
| **坊市** | 买卖（已有实现） |
| **客栈** | 住宿（回灵气）、打听消息 / 情报 |
| **藏经阁** | 功法购买 / 参悟（接 P3 书库与理解锁） |

> 传送阵 / 驿站 / 拍卖行 / 悬赏榜 / 宗门山门**下个版本再加**。

### 6.3 场所限制（接 P3.7 遗留"场所系统未实现"）

- ✅ **限制场所**：闭关 / 参悟 / 突破需要"静室"级场所，**效率由场所等级决定**。
- ✅ 场所**可获取、可升级、可布置**：

| 形态 | 获取 | 特点 |
|---|---|---|
| 客栈房间 | 租，按天收费 | 分级：普通房 / 上房 / **带聚灵阵的静室**，即时可用 |

- 🔧 **洞府子系统**（开挖 / 升级 / 布置）**单独立项，本定案只占位**，不在地图地基里实现。
- ✅ 城内时间**按动作结算**（交易 0 日、打听 1 日、住宿 1 日）。

## 七、存档模型（无位图）

```python
save = {
  "world_seed": 20260910,            # 世界唯一真相
  "t": 1523400,                      # 息
  "pos": [8412.5, 3307.25],          # 里（连续坐标）
  "discovered": ["mine_苍梧_03", ...],        # 已知内容点（有限集合）
  "places": {"town_青石镇": {"visited": True, "cleared": False}, ...},
  "world_diff": {"域_07": {"faction": "青云宗"}, ...},
  # 玩家自身（背包 / 功法 / 熟悉度…，沿用现有结构）
}
```

| 东西 | 存不存 | 原因 |
|---|---|---|
| 地形 / 路网 / 城镇布局 | ❌ 不存 | `f(world_seed, x, y)` 纯函数重建 |
| 探索度位图 | ❌ **不存** | 舆图已给地形；内容点是有限枚举 |
| 内容点发现状态 | ✅ `discovered` 集合 | 有限、稀疏 |
| 地点状态 | ✅ `places` 字典 | 有限（200–300 个） |
| 世界变化 | ✅ `world_diff` 稀疏字典 | 势力 / 被毁 / 开启的秘境 |

> 存档规模预期**几十 KB 级**（对比 Minecraft 的几百 MB：我们地形不可改、内容为枚举点、世界有边界）。
>
> **一片沼泽只需要"有没有内容点、发现没有"这一个 bit，不需要逐格标记。**
