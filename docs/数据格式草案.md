## 一、总览：数据文件分类

| 文件           | 内容                                        | 谁来写                   |
| -------------- | ------------------------------------------- | ------------------------ |
| `manual/`    | 手写精品：核心功法/关键NPC/主线事件模板     | 你手写                   |
| `generated/` | 生成器批量产出：变体功法/物品/敌人          | 生成器（套 manual 模板） |
| `settings/`  | 境界表、五行克制矩阵、区域浓度、掉落表      | 你手写（半配置）         |
| `runtime/`   | 组装后的最终数据（合并 manual + generated） | 构建脚本                 |

## 二、五行与境界（settings）

### 五行向量（一切属性签名的基础）

每个功法/物品/敌人带一个五行向量，五个数字，和为 1（或 0~N 的权重）：

```json
{ "金": 0.1, "木": 0.2, "水": 0.3, "火": 0.3, "土": 0.1 }
```

### 境界刻度（机制刻度，已定）

**练气保留"一至九层" + 筑基/金丹/元婴/化神 各分初/中/后/大圆满 = 25 档**，连续刻度 1–25：

```json
1=练气一层  2=练气二层  ...  9=练气九层
10=筑基初期  11=筑基中期  12=筑基后期  13=筑基大圆满
14=金丹初期  ...  25=化神大圆满
```

> 练气九层 = 开局新手教程 + 第一个抉择密集区（每层有小突破/事件）；筑基起进入标准四段节奏。机制层不需要每个档号都有独立意义，只需提供"比较参照"。

**双粒度用法（关键）**：

- **二值门槛用大境界**（理解锁、技能亮、神通点亮）——看不懂就是看不懂，不分小阶，粒度到 5 即可，保持简单。
- **连续数值对照用细刻度**（25 档）：宝光是否需要藏、敌人强度匹配、掉落品阶对照、寿元曲线、灵气池成长，全部以档号为参照。宝光值因此有了精确设计空间（见物品节）。

### 五行克制矩阵（机制核心，一张 5×5 表）

```
        目标:金  木  水  火  土
攻击:金   1.0  1.5  0.8  1.0  0.8
攻击:木   0.8  1.0  1.5  0.8  1.0
攻击:水   0.8  1.0  1.0  1.5  0.8
攻击:火   1.0  0.8  1.0  1.0  1.5
攻击:土   1.5  0.8  1.0  0.8  1.0
```

> ⚠️ 数值待定，此处仅示意。金克木→1.5，水生木→喂气 0.8 之类，按你 earlier 的"克=优势、生=喂气"思路填。

## 三、功法（核心实体）

```json
{
  "id": "manual.huo_yang_jue",
  "name": "火阳诀",
  "origin": "manual",           // manual 手写 | generated 生成
  "template": "火系主修功法",    // 生成的变体记录其母模板

  "realm_gate": "练气",          // 理解锁：至少这个境界才看得懂
  "slot_type": "主修",           // 主修 | 战斗 | 身法   ← 决定能进运转池哪个槽

  "element": { "金": 0.0, "木": 0.0, "水": 0.0, "火": 0.8, "土": 0.2 },
  "affinity_cost": 3,            // 占用多少"道基容量"？(若做容量概念)

  "effects": {                    // 被动效果（功法层=被动主体）
    "cultivate_bonus": 1.2,      // 修炼效率倍率
    "mp_max_bonus": 30,          // 灵气池上限加成
    "fire_damage_bonus": 0.15,   // 火系伤害加成
    "on_breakthrough": []        // 突破时特殊加成（可空）
  },

  "skills": [                     // 1~4 个技能（功法自带）
    {
      "id": "skill.huo_yang_jue.yan_sha",
      "name": "焰杀",
      "unlock": {"realm": "筑基", "familiarity": 60},
      //   ↑ 理解锁破境后参悟；熟悉度到 60 才亮此技能
      "cost": {"qi": 25},
      "type": "攻击",
      "element": "火",
      "damage": {"base": 40, "mult": "attack"},
      "requirement": "温和",      // 需求谱系：无需求/温和/严格
      "desc": "炽焰凝线，直取咽喉。"
    }
  ],

  "familiarity": {               // 参悟/熟练度配置
    "per_day": 0.5,             // 闭关参悟每天涨多少
    "per_use": 0.1,             // 战斗中使用一次涨多少
    "max": 100,
    "unlock_at": [60, 100]      // 熟悉度节点：60 亮技能1，100 亮技能2
  }
}
```

## 四、物品（器物/功能类）

```json
{
  "id": "generated.weapon.jian.xuan_han",
  "name": "玄寒剑",
  "origin": "generated",
  "template": "武器-剑",

  "category": "武器",            // 武器|防具|法宝|储物|飞舟|丹药|材料|杂物
  "subtype": "剑",
  "tier": "筑基级",               // ✅ 强度语言=境界层级：练气级/筑基级/金丹级/元婴级/化神级（生成时按模板定死）
  "rarity": "地阶",               // 品阶(凡品~圣阶)=纯稀有度/价值/风味词，不承载机制强度
  "element": { "水": 0.9, "金": 0.1 },   // 器物线本身无属性；此为"自带神通"用的签名

  // 器物线（物理底子，拿得起即生效，无境界门槛）
  "equip": {
    "attack": 25,                // 物理攻击（受品阶影响）
    "slot": "武器"
  },

  // 可选：自带神通（极少数高品阶才有；按大境界解锁）
  "artifact_skill": {
    "name": "寒渊斩",
    "realm_unlock": "金丹",       // 到金丹才亮（整体点亮，无逐条灰）
    "element": "水",
    "cost": {"qi": 40},
    "desc": "一剑出，霜寒百里。"
  },

  "spirit_light": 11,            // 宝光强度，用 20 档境界刻度作参照系
                                 // 规则：宝光 > 玩家境界档 + 容差(待定，如+1) 才需要藏
                                 // 例：练气中期(档2) 拿宝光11 的剑 → 完全藏不住，危机
                                 //     金丹后期(档11) 持同剑 → 压得住，威仪
                                 // 设计空间：品阶→宝光映射表、储物袋压光上限、掩息手段加成

  "value": 800,                  // 基准价（灵石）
  "weight": 3,                   // 掉落权重（给掉落表用）
  "desc": "剑身幽蓝如渊，寒气自生。"
}
```
