## 1. 工作方式（重要）

- 用户主导设计，早期大量轮次讨论定案，随后转为**分阶段 subagent 实现**。
- **主会话角色**：写任务书（`docs/tasks/P<n>-<名>.md`，字段级规格+验收判据）→ 派 subagent
  → 独立复核（不盲信 agent 报告：自己跑单测/smoke/断言）→ 勾选 `docs/实现路线图.md` → 写下一份任务书。
- subagent 看不到历史对话，任务书必须自包含（含必读清单）。串行执行（同代码库避免并行踩踏）。
- 中文字符串在 Windows 控制台：命令前缀 `$env:PYTHONIOENCODING='utf-8'` + `python -X utf8`。
- 验收基线命令：`python -X utf8 -m tests.smoke`（20局分布）、
  `python -X utf8 tests\test_battle.py`（52项）、`python -X utf8 tests\test_gongfa_deep.py`（89项）、
  `python -X utf8 tests\test_server.py`（P3.6 Web 壳 69项）。
- 本机无 git 仓库（`git status` 不可用）；复核改动靠直接读文件比对。

## 3. 当前代码的已知取舍（agent 报告+复核确认，别当 bug 改）

1. **防御技仍与"防御"动作等效**（本回合受伤减半，未差异化）；无 heal/治疗类（青木回春也是防御效果）。
2. **战败心魔 min(95, +10)**（防走火即死）；**exp 减半不跌境界**——残废态属 P4。
3. **数值全占位**：settings.py 与 content 中 hp/伤害/价格/掉落/熟悉度节奏都是占位，可任意标定。
   熟悉度参数：PER_DAY=2.0、PER_USE=1.0、FAM_ENTRY=10（5 天入门）、unlock_fam 10/30/80。
4. 五行只做"克"环（×1.5/×0.5）；"生"环与威力层留 P5。五行"生"的语义 = 给对方喂气(0.8类)。
5. `_active_battle` 运行时状态不入存档；读档/回溯回战斗前节点（设计如此）。
6. **战斗槽可购功法仅 3 本**（撼岳诀 t1/沧澜诀 t10/庚金杀剑 t14），不满 4 槽——槽上限由引擎兜底，
   内容补足属 P8 生成器或后续手写。
7. smoke bot 只在"含攻击技且加成更高"的主修间换装；不主动玩战斗槽/身法槽的 utility 效果
   （真实玩家玩法待验证，判据已由单测覆盖）。
8. P3 已解决的旧遗留（勿再当问题报）：无"拥有记录"→ 已补 owned_gongfa + 重复购功法拒绝；
   battle/shenfa 槽 → 已开放；utility 无战斗效果 → 已做最小效果集；"能买就能学" → learn 需 拥有+看懂+入门。
9. **P3.6 新取舍（Web 壳层实现决策，勿当 bug）**：
   - `GameSession.step` 对**所有**动作（含 status/market 等信息型）每步落盘 run json（任务书 B「每步都落盘」），
     CLI 只在部分指令后落盘——落盘节奏比 CLI 密，但存档内容与 CLI 等价（risky 才写 .cp.json，与 CLI risky() 一致）；
     战斗内每回合也落盘（CLI 战后写一次），战斗中 HP/灵气不入档（设计如此）。
   - undo 只退一步且节点在会话内存中——重启后无可回溯节点（返回 `no_checkpoint`），与 CLI 一致（.cp.json 仅镜像，
     CLI 从不读它）；重启续玩靠 run json。
   - `/api/new` 固定 seed 会覆盖同 seed 旧档（同 CLI `--seed` 语义）；`run_id = str(seed)`，CLI 与 Web 同目录互通。
   - 服务层错误 unknown_run/bad_request/no_checkpoint 用 HTTP 4xx + `{"ok":false,"reason":...}`；
     引擎拒绝分支 HTTP 200 + `ok=false` + 引擎 reason 原样透传（前端只按 reason 映射提示）。
   - 面板错误提示 = JS 内 REASON_TEXT 映射（reason → 中文），禁解析 text；`text/lines` 只进日志流。
10. **P3.6 引擎顺带修复（玩法/数值零改动，复核确认）**：① 补 `R_NOT_IN_BATTLE = "not_in_battle"`
    常量（§5.2 已列码、常量缺失 → 场外 battle_action 必 500）；② `Game._migrate_state` 对 familiarity
    int 键 JSON 往返归一（读档后熟悉度归 0 的真 bug，inventory 同型迁移早已存在）。
