## 3. 当前代码的已知取舍（agent 报告+复核确认，别当 bug 改）

    - **突破寿元 = 加差额**：`寿元 += (新基准−旧基准)`；小境界基准相同 → 寿元不变。不要再写回
      `lifespan = 基准×系数`（那会把折寿抹平）。
    - **身死拦截在 `step()` 开头**：只有 status/chronicle 放行；CLI 主循环本来就在 `not alive` 时 break。
    - **坊市门槛**：`market` 与 `buy` 一致要求 `location == 坊市`（同码 `not_at_market`）；Web 端离开坊市
      即收起货单面板 + 禁用「货单」按钮。
    - **`_as_int` 是唯一数值入口**：`step()` 内所有数值参数必须经它，禁止再写裸 `int(kw[...])`。
    - `main.py test` 目标列表新增 test_hardening（在 test_effects 之后）。
