## 二、用户拍板的决策（逐条）

**地图与空间**

1. 世界 **20000 里见方**、**25 域（5×5）**、每域 4000 里；域内折返约 1 年、跨全图约 2.5 年（步行）
2. **连续坐标**；"格"不是设计概念，只是**局部、按需、可丢弃**的加速结构
3. **精度与内存解耦**：全局只物化稀疏特征（河/路/城/灵脉），地形按需采样
4. 三档尺度：**世界 / 地点 / 秘境**（相机推进 + 规则切换，坐标空间不变）
5. 越野基线 **22 里/日**、官道 44；飞行 **250 里/日**、金丹起
6. 有舆图→候选路径（最快/最安全/最隐蔽）+ 过滤器；无舆图→**手动探路**
7. 地图三档：无舆图 / 粗舆图 / 详图（可买卖）
8. 城镇内 = **同一坐标系的小数**；v1 做**设施点摆放**，预留"城内小图"扩展位
9. v1 设施 = **坊市 / 客栈 / 藏经阁**；场所限制：闭关等需"静室"级场所
10. **不做**：格子地图（设计概念）、逐格探索度位图、真几何嵌套、流式加载

**时间**

11. 统一到**息**（整数）；世界/战斗/移动共享一条轴；年龄按整日结算
12. 昼夜五行段：木/火/金/水 + 土旺四季；接威力层
13. **视野回退定案原值**（60/150/400/1000/2500）——"视野 ≥ 格宽"是伪约束

**路与河**

14. 路网是**图**不是地形带；宽度按真实尺度：
    官道 0.02 里（10 m）/ 容差 0.05；小径 0.004 里 / 容差 0.02
15. 河流 0.05–0.4 里（25–200 m）**沿程渐变**；渡口沿弧长每 600 里一个
16. 格级采样"**格内有路即算路**"，点级采样按真实路面宽度

**流程与文档**

17. 提交规范：`<type>(<scope>): <中文>`；一个提交一件事；文档与代码分开
18. 路线图重排（见 §一 #14）
19. 项目名《一世问道》，文件夹 `yishi-wendao`

## 三、我犯的错与纠正（诚实记录）

| # | 错误 | 纠正 |
|---|---|---|
| 1 | **视野修错方向**：为满足"视野 ≥ 格宽"把练气视野 60→200 | 用户指出该约束是"地形按格取常数"时代的产物；**回退原值**并删掉伪约束 |
| 2 | **50 里重标定半途**：改常量后 21 项测试红 | 分类整理（硬编码 / 密度膨胀 / 边界冲突）→ 存 `wip/grid-50` 分支，后来才收完 |
| 3 | `cost_field` 在 `_ensure_*` **之前**读 `_elev` | 首次为 `None` → 坡度项**静默失效**；移到正确位置后路网才真的弯 |
| 4 | 编辑时**误删一行**（`if name in used_names:`） | 语法检查抓出并修复 |
| 5 | 编辑时插入**字面量 `` `n ``**（PowerShell 单引号不解析转义） | 二次替换修掉 |
| 6 | `G50a` 断言按"官道格绝对数"比较 | 避路会让路径变长、格数更多 → 改**占比**并均匀取样 |
| 7 | 误以为"粗犷"指内存（估 82 MB） | 实测只有 `_elev` 常驻（~5 MB）；真问题是**代价场全图物化** |
| 8 | 把"结算"理解成游戏内结算 | 用户要的是**对话结算**（本文件）；多写的 `设计-结算与转世.md` 属意外产出 |
