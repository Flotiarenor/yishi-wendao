# 结算与转世 · 设计思路（P6）

> 状态：**思路稿**（2026-09-10）。落地排期见 `实现路线图.md` **P6**。
> 上游依据：`设计定案.md` §二（时间/存档）、§三（死亡/残废/转世）。

---

## 一、结算在系统里的位置

一世 = 一个存档 = 一条 roguelite 跑道。**结算是这条跑道的终点页**，也是下一世的起点页。

```
道陨（寿元耗尽 / 心魔爆发）
      ↓
   结算页  ← 本文件定义
      ↓
  转世点数 → 开局配点 → 新一世的种子与起点
```

**触发条件（当前实现）**：`Player.alive=False`，`death_cause` 二选一：
- `寿元耗尽，坐化于{境界}（享年 N 岁）`
- `心魔反噬，走火入魔而亡`

**预留触发**：P11 突破考验的"走火入魔"若严重到不可逆，也应汇入结算（残废态则是"还活着"，不结算）。

---

## 二、核心原则（与定案一致）

1. **不继承"成就"，只继承"起点"**——上世的功法/技能/灵石/储物全部清零；能带走的只有"下世开局条件的改善"。
2. **业力不跨世**——每世善恶清零；功德/业力只在局内影响突破天劫。
3. **结算必须可复现**：所有数字只从**存档内数据**推导（`Chronicle.entries` / `Player` 字段），不依赖外部统计、不做随机。
4. **结算是只读页**：除"开始下一世"外不改变任何局内状态，因此**不消耗随机流**。

## 三、结算页要素

| 区块 | 内容 | 数据来源（已具备） |
|---|---|---|
| **结局定调** | 道陨 / 走火入魔 + 一句话墓志（按境界档位分档写模板） | `Player.death_cause`、`realm_idx` |
| **编年史回顾** | 时间线（已有）按**里程碑**折叠：破境、重大战斗、获得高阶功法 | `Chronicle.entries` |
| **成就统计** | 达境界档 / 存活年数 / 战斗胜败逃 / 去过多少地点 / 功德·业力净额 / 心魔峰值 | 多数需**新增埋点**（见 §六） |
| **本世评分** | 单一总分（用于转世点数），分档展示 | 公式见 §四 |
| **转世预览** | 下世可花的点数 + 可解锁的起点选项 | 同上 |

**呈现（沿用 P3.7 已拍板的布局）**：结算页**接管主内容区**（不做覆盖层），叙事日志保留在下方；
「开始下一世」是唯一主动作。

## 四、转世点数（占位公式）

```
本世评分 = 境界档 × 2
         + 存活年数 / 50
         + max(0, 功德净额) / 10
         + 大事纪条数 / 20
         - 心魔峰值 / 20
转世点数 = round(本世评分)  ，下限 1
```

- 全部为**占位**，可任意标定（P12）。
- 设计意图：**把"活得久、走得远、行得正"折成下世的优势**，而不是鼓励速死重开。
- **不设"目标评分"**——它是 roguelite 的成长曲线，不是 KPI。

## 五、开局配点（下世起点）

- 池子：**体质 / 悟性 / 气运 / 出身**（与现有 `Player.spirit_root` / `root_mult` / `lifespan_mult` 对接）。
- 每项 0–3 级，逐级变贵（`1 / 2 / 4` 点），高等级**需先解锁**（由上一世评分达档解锁）。
- **出身**额外带"起点地点"与"初始功法"差异（与 `content/sites.py` 锚点、`gongfa` 赠送链对接）。

## 六、落地的四步（每步可独立验收）

| 步 | 内容 | 需要新增 |
|---|---|---|
| **S1 结算页（只读）** | 道陨后显示：结局 + 编年史折叠 + 现有可统计项 | 前端结算视图 + `game.settlement_data()` |
| **S2 成就埋点** | 补统计字段：战斗胜/败/逃、去过地点集合、获得高阶功法数、心魔峰值 | `Player`/`GameState` 加只读计数（**不参与判定**，故不改行为指纹） |
| **S3 转世点数 + 配点界面** | 评分公式 + 开局配点（点数为 0 时等价于现状） | 存档新增 `meta`（跨世，独立于 `GameState`） |
| **S4 起点解锁** | 高等级起点需上世评分解锁；出身差异接地点/功法 | `meta.unlocked` |

⚠️ **`meta`（跨世数据）必须与 `GameState`（一世数据）分文件存放**——前者不随"固定种子 + 节点回溯"回档。

---

## 七、验收判据（逐条可判定）

1. 道陨 → 结算页可见：结局文案、编年史条数、评分、转世点数 —— 前端 E2E。
2. 相同存档算出的评分与点数**逐位一致**（纯函数、可单测）。
3. 结算**不消耗随机流**：调用前后 `rng.cursor` 不变 —— 单测。
4. 点数为 0 时开局配点等价于当前默认开局 —— 回归测试。
5. 业力不跨世：新世 `karma == 0`、`owned_gongfa` 只有赠送功法 —— 单测。

## 八、明确不做（第一版）

- ❌ 转世保留任何功法/灵石/储物
- ❌ 跨世成就墙、图鉴、排行榜（无联网、无账号）
- ❌ 结算页存档导出/分享
- ❌ 与 Web 壳之外的平台对接
