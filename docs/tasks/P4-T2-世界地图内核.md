## 一、为什么要重构（首版实现的偏差）

首版把**地形 / 高程 / 五行全部量化到 100 里格**：

```python
WORLD_CELL_LI = 100.0          # 栅格边长
def terrain_at(x, y):
    cx, cy = cell_of(x, y)     # floor(x/100)
    return self._terrain_cell(cx, cy)   # 整格同一地形 ← 问题所在
```

后果：

| # | 症状 |
|---|---|
| 1 | 地形在格内是常数 → **地图本质上是 200×200 方块图**，"格"从加速结构变成了设计概念 |
| 2 | 五行浓度（`element_at`）继承同一量化 → P5 会一并被绑死 |
| 3 | 路网"落格"（`Road.cells`）→ **一条官道占满 100 里见方的整格**，"站在路上"判定粗到没法用 |
| 4 | 练气期神识半径 60 里 **< 格宽 100 里** → 迷雾揭示退化为"整格翻转" |
| 5 | 全图预生成 `_base` / `_elev` 数组 → 精度与内存绑定，**想提高精度就必须重写整条链** |

**根因**：定案只写了"格不是设计概念"，**没写精度从哪来**。现已补 §3.5：**全局只物化稀疏特征，地形一律按需采样。**

## 二、核心原则（本任务书的判据来源）

1. **地形 / 高程 / 五行 = 纯函数按需采样**，任意 `(x, y)` 可调，**零存储**。
2. **全局只物化稀疏特征**：河流 / 路网 / 城镇 / 灵脉 / 内容点（数量级：百 ~ 千）。
3. **覆盖层用几何而非栅格**：路 / 河 = **折线 + 宽度**，判定 = 点到折线距离。
4. **代价场按窗口惰性生成**，用完即弃；分辨率由调用方指定。
5. **视野半径 ≥ 特征栅格宽度**，保证迷雾渐进揭示。
6. **确定性不放松**：同 `world_seed` → 跨进程逐位一致（不依赖内置 `hash`、不依赖 `set` 迭代序）。

## 三、字段级规格

### 3.1 连续地形采样（T2-R1，核心）

新增模块级函数：

```python
def classify_point(seed: int, x: float, y: float) -> int:
    """任意坐标 → 基础地形 id（不含覆盖层）。纯函数、无实例状态。"""

def sample_fields(seed: int, x: float, y: float) -> tuple:
    """返回 (elev, moist, temp, fire, slope)，均归一化到 [0,1]；供分类与调试。"""
```

- `elev / moist / temp / fire`：现有 `fbm` 场（周期/倍频**保持不变**：6400/5、4800/5、8000/4、3000/3）。
- `slope`：在 `(x±_SLOPE_EPS, y)`、`(x, y±_SLOPE_EPS)` 各采一次高程，取 `max−min`；**`_SLOPE_EPS = 2.0` 里**。
- 分类顺序与阈值**沿用现有 `_classify`**（沙漠/沼泽/林地早于丘陵），仅把输入换成连续采样。
- **性能**：单点 ≤ **10 µs**（现状 `fbm` 单次 3.3 µs；5 次采样 + 分类应在 20 µs 内，可接受）。

`WorldMap` 对外接口（**签名保持兼容，语义改为连续**）：

| 方法 | 语义 |
|---|---|
| `terrain_at(x, y, with_roads=True)` | 任意坐标 → 地形 id（覆盖层优先） |
| `base_terrain_at(x, y)` | 任意坐标 → 不含覆盖层的地形 id（**新增**；替代 `base_terrain(cx, cy)`） |
| `elevation_at(x, y)` | 连续高程 [0,1]（**不再取格值**） |
| `element_at(x, y)` | 连续地形主五行 + 域叠加 |
| `terrain_at_cell(cx, cy)` / `base_terrain(cx, cy)` | **保留**，内部转格心坐标调用连续版（兼容旧调用与渲染降采样） |

- ❌ **删除** `self._base` / `self._elev` 全图数组（不再预生成地形）。
- ✅ 允许实例内**小窗口缓存**（LRU ≤ 4096 点），但**不得**退化为全图数组。

### 3.2 覆盖层改几何（T2-R2）

```python
@dataclass(frozen=True)
class Road:
    kind: str              # "road" / "trail"
    points: tuple          # 折线（里），世界坐标
    width_li: float        # **真实路面**：官道 0.02 里（10 m）/ 小径 0.004 里（2 m）
    tol_li: float          # **判定容差**（独立于路面）：官道 0.05 里 / 小径 0.02 里
    from_id: str; to_id: str
    length_li: float

@dataclass(frozen=True)
class River:
    points: tuple
    width_li: float        # **真实河面**：0.05–0.4 里（25–200 m），**按长度渐变**
    fords: tuple           # 渡口点（里）
    length_li: float
```

- **路网是图，不是地形带**（定案 §4.4）：沿路移动走边，越野走代价场；宽度只用于"是否站在路上"与渲染。
- **判定**：`overlay_at(x, y)` = 点到 road/river 折线距离 ≤ `tol_li`（路）/ `width_li/2`（河）→ 返回对应地形。
- **渲染视觉宽度独立**（1–2 px），与真实宽度无关。
- **加速**：按 100 里格分桶建空间索引（`idx → [segment, ...]`），查询只看本格 + 8 邻格的段。
- **渡口**：`T_FORD` 判定 = 距渡口点 ≤ 0.03 里，且**优先于** `T_WATER`。
- ❌ **删除** `_road_cells` / `_town_cells` 的"整格覆盖"语义（`_town_cells` 改为"城镇半径内"）。
- ✅ 城镇：`Town(x, y, radius_li, facilities)`；`radius_li` 内视为城镇地形（`T_ROAD`）。
- ⚠️ `Road.cells` / `PathResult.cells` **可保留**作为调试/ASCII 视图的降采样，但**不得**再作为地形真相。

### 3.3 代价场窗口化（T2-R3）—— ⚠️ **本节规格已作废，见文首状态告示第 2 条**

> 原始规格保留如下（**仅供追溯当时的设计意图**）：

- `cost_field(..., box=(x0, y0, x1, y1), step=...)`：**只在 box 内采样**，返回 `CostField`。
- `box=None` → 全图粗采样（`step` 默认放大到 100 里），**明确允许**（用于概览/连通性分析，不用于玩家寻路）。
- `CostField.passable/cost` 仍收**格坐标**，但格的边长由 `step × 100 里` 决定（`step=1` 即 100 里格；未来可 `step=0.1` 得 10 里格）。
- ⚠️ **窗口大小上限**：单次 `cost_field` 采样点数 ≤ **250 000**（≈0.5 s），超出则自动放大 `step` 并返回实际步长。
- A\* 保持现有实现（已是窗口化 + octile 启发 + 防穿角），只换代价来源。

### 3.4 视野（T2-R4，2026-09-10 修正）

**保持定案原值，不因格宽调整**：

```python
VISION_RADIUS_LI = (60.0, 150.0, 400.0, 1000.0, 2500.0)   # 练气→化神（里）
```

- ❌ **不要**为了"视野 ≥ 格宽"而抬高视野——地形已连续采样，迷雾遮的是**内容点**而非"格"。
- 视野大小的最终标定归 **T4 迷雾**（与内容点密度一起定）。
- 单测断言：半径 > 0 且随境界单调不减。

### 3.5 确定性

- 采样链全程只用 `hash01` / `splitmix64` / `fbm`（**禁止内置 `hash`**）。
- `terrain_checksum()` **语义变更**：改为对"特征集合"（河/路/城/灵脉/内容点 + 一批固定采样点）求摘要，
  **不再**对全图 `_base` 求摘要；固定采样点用确定性网格（如每 250 里一点 → 80×80 = 6400 点）。
- 跨进程一致（子进程复算比对）。
