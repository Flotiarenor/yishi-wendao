  `../实现路线图.md` 对应阶段条目，然后 `git mv` 到 `../archive/tasks/`。
- ⚠️ **口径规则（2026-09-10 统一）**：
  1. **现状数字只在根 `README.md`「当前状态」事实表维护**——任务书里**不要复制**测试项数 /
     指纹 / 格宽 / 视野 / 性能等数字；需要时写「以根 README 事实表为准」。
  2. 任务书写作时的基线数字若必须留在文里，**加"（当时）"前缀**，并在文首告示里说明已过时。
  3. **规格被实测推翻时不要删**：在条目标注「⚠️ 已作废 + 作废理由 + 结论出处」，
     保留原始意图——否则下一个会话会照着作废规格重做一遍（P4-T2 §3.3 就发生过一次）。
