## 二、T1 时间刻度统一到息（先做，行为中性优先）

### T1.1 `engine/settings.py` 加时间单位（全部整数常量）

```python
SI_PER_KE       = 450     # 1 刻 = 15 分
KE_PER_SHICHEN  = 8       # 1 时辰 = 8 刻
SI_PER_SHICHEN  = 3600    # 1 时辰 = 2 小时
SHICHEN_PER_DAY = 12
SI_PER_DAY      = 43200   # 1 日
DAYS_PER_MONTH  = 30
SI_PER_YEAR     = SI_PER_DAY * DAYS_PER_YEAR   # 15_552_000
SHICHEN_NAMES   = ("子","丑","寅","卯","辰","巳","午","未","申","酉","戌","亥")
```

昼夜五行段（接 `设计定案.md` §六 威力层）：

| 段 | 时辰 | 五行 |
|---|---|---|
| 平旦 | 寅卯辰 | 木 |
| 日中 | 巳午未 | 火（午时最盛） |
| 日入 | 申酉戌 | 金 |
| 夜半 | 亥子丑 | 水 |

**土旺四季**：辰/未/戌/丑 额外叠土。

新增纯函数（放 `engine/settings.py` 或新 `engine/timeutil.py`，**无 I/O**）：
`day_of(t)`、`shichen_of(t)`、`day_phase(t) -> (段名, 主五行, 叠加五行)`、`format_time(t) -> "第三日 · 午时"`。

### T1.2 `GameState` 改以 `t`（息，int）为唯一时钟

- 新增 `t: int = 0`；`day` 改为**只读属性** `t // S.SI_PER_DAY`（保持既有语义）。
- `to_dict()` 同时写 `t` 与 `day`（兼容旧读者）；`from_dict()` 优先读 `t`，缺省用 `day * SI_PER_DAY` **迁移旧档**。
- `age_years` 仍按 `round(day / DAYS_PER_YEAR + 16.0, 2)` 计算（**T1 阶段不改年龄精度，避免指纹漂移**）。

### T1.3 `_advance_days(days)` 改为推进 `t`

```python
def _advance_days(self, days: int):
    self.state.t += int(days) * S.SI_PER_DAY
    self.state.player.age_years = round(self.state.day / S.DAYS_PER_YEAR + 16.0, 2)
    self._regen_qi(days)
```

### T1.4 战斗耗时接回世界轴（**唯一允许的指纹变化**）

- `Battle` 内部 `t` 是厘息（相对开战）；战斗结束时把 `battle_t_li // 100`（向上取整，最小 1 息）加到 `state.t`。
- 需在 `_finish_battle`（胜/败/逃三条路径**都要**）调用；战斗内花费的时间要进 `data`（如 `data["battle_si"]`）。
- 预期效果：打一场 ~392 厘息的战斗 ≈ 4 息（8 秒），**不足以推动一天**——这是刻意的（寿元仍按天结算）。

### T1.5 `QI_REGEN_PER_DAY` 重标

现注释与"1 息 = 2 秒"矛盾（`settings.py:95-96`）。按 43 200 息/日重标：
`QI_REGEN_PER_DAY` 应改为"每日恢复量"的显式常量，并让 `_regen_qi` 用 `si` 计算（`qi += si * QI_REGEN_PER_SI`），
避免"按天数整数结算"漏掉战斗那几息。

### T1.6 对外暴露

- `state_data()` / `session.py` 的状态负载增加 `t`、`shichen`、`time_text`（古风串），**保留 `day` 字段**（前端与测试已依赖）。
- `tools/replay.py` 指纹字段增加 `t`（保留 `day`）。

## 三、T2 世界地图内核（`engine/worldmap.py` + `content/regions.py`）

- 连续坐标 `(x, y)`（float64，单位里，原点西南角），世界 20 000 里见方、25 域（5×5）。
- 地形 12 种 + 硬阻挡（见定案 §3.3 表）；地形由 `world_seed` + 多倍频噪声**确定性生成**（纯函数）。
- 代价场：`speed(terrain) × 境界系数 × (1+身法)`；寻路 = 代价场上的 A\*（一套算法通吃最快/避开大路/避开障碍/越野/飞行）。
- 路网：城镇选址（沿河/山口/平原交界）→ 城镇间**最小代价路径**自动生成。
- **零 I/O、零随机**（随机只来自 `world_seed` 的确定性派生）；`tests/test_worldmap.py` 覆盖。
