## 目标

把"功法"从"装备一件加成的物品"升级为**养成系统**，落实用户原设计链条：

```
获得 → 看懂(境界够) → 参悟(闭关投天数) → 学会(熟悉度≥FAM_ENTRY 可入运转池)
     → 运转(占槽生效) → 持续参悟+战斗使用 → 熟悉度上涨 → 逐层解锁技能 + 道基被动
```

- 理解锁生效：境界不到看不懂（只有书名/层级/来历）
- 参悟动作 + 熟悉度：闭关天数投给参悟 vs 投给修为 = 玩家抉择；技能按熟悉度节点解锁
- 需求谱系生效：free（独立术法，恒可用）／温和（母功法在运转池任意槽）／严格（母功法在主修位 或 熟悉度大成）
- 双池：领悟池（已拥有/已参悟，无限）vs 运转池（主修 1 + 战斗 4 + 身法 1）；**池外功法完全不生效**
- battle/shenfa 槽位开放（P2 遗留：庚金杀剑/御风步法可购不可装）
- 战斗技能来源 = 运转池功法的已解锁技能（按谱系过滤）+ free 独立术法；utility 类技能**最小战斗效果**落地
- 开局赠书改为**基础吐纳功法**（用户 2026-09-08 拍板）：熟悉度 0 起步走完整教学链；带一个温和主动技（聚气类，提升灵气回复）；**习得（熟悉度≥FAM_ENTRY）后永久 +5% 修炼效率、不占槽生效**

**明确不做**（防范围膨胀）：12 格战斗编组（技能库尚小，P3 把满足条件的技能全量亮出，槽位格 UI 留后期）、heal/治疗类、战斗内丹药、五行"生"环与威力层（P5）、宝光/藏匿、突破考验（P4）、掉落获取功法（P8 才扩获得渠道）。除吐纳诀外**不再有第二本** permanent_bonus 功法（"余位被动"扩展位，仅此一例验证机制）。

## B. 定案速览（本任务书的规则定案；有疑点按 A 节原则取舍并记录）

1. **看懂门槛 = 功法 tier 档号**：`p.realm_idx >= gf.tier`（tier 恒取大境界起点档 1/10/14/18/22）。看懂与否**派生，不存档**。
2. **熟悉度**：0~FAM_MAX(100) 只升不降。来源仅两条：闭关参悟（days×FAMILIARITY_PER_DAY）与战斗使用该功法技能（每次 +FAMILIARITY_PER_USE，战斗结束统一结算）。熟悉度≥FAM_ENTRY(10)= **已入门/已学会**：可入运转池、其 permanent_bonus 开始永久生效。熟悉度 <FAM_ENTRY = 参悟中。
3. **参悟是独立动作**（闭关模式二选一：修为 or 参悟某功法），消耗真实天数，可 checkpoint/回溯。
4. **技能解锁**：技能亮出条件 = 母功法熟悉度 ≥ skill.unlock_fam（free 技能 unlock_fam=0 恒亮）。**亮出 ≠ 可施放**：施放还需需求谱系满足（见 5）。
5. **需求谱系（施放条件）**：
   - `free`：独立术法，无母功法依赖，恒可施放（在战斗池）。
   - `温和 gentle`：母功法在**运转池任意槽**即可施放。
   - `严格 strict`：母功法在**主修位**，**或**其熟悉度达 **FAM_MAX（大成）**。
   - 一技能被多本功法引用（如烈焰斩=炎阳诀+焚天诀）：任一母功法满足即视为满足。
6. **运转池槽位**：主修 1（=main_gongfa，字段保留）+ 战斗 4（battle_gongfa 列表）+ 身法 1（shenfa_gongfa 列表）。槽位**只能装同 slot_type 的功法**（main 类→主修位；battle 类→战斗槽；shenfa 类→身法槽）。槽被占时须先卸（保留 P1"先 forget 再换"的交互）。**槽位上限与身法槽数量由 settings 常量控制**（BATTLE_SLOTS=4 / SHENFA_SLOTS=1，身法 1~2 取 1，留扩展）。
7. **池外完全不生效**：非运转池功法——其修炼加成/道基被动之外的一切不生效、技能不进战斗池。（道基被动属例外：习得即永久，见 2。）
8. **修炼效率公式**（替换现 `root_mult×(1+main_bonus)`）：
   `效率 = root_mult × (1 + Σ已习得功法permanent_bonus) × (1 + 主修cultivate_bonus)`
   （Σ 遍历"熟悉度≥FAM_ENTRY 且 permanent_bonus>0"的功法；P3 只有吐纳诀命中）
9. **utility 最小战斗效果**（数据字段 utility_effect 驱动，kind=utility 才有；无 effect 的 utility 不入战斗池）：
   - `"breath"` 吐纳：施放立即回复灵气（量级建议 ≈ qi_regen×3，数值可调）
   - `"root"` 定身：敌方**本回合行动跳过**
   - `"weaken"` 破势：敌方**本回合造成伤害 ×0.5**
   - `"evade"` 御风：敌方**本回合攻击 50% 概率落空**（消耗随机流）
   效果标记只存在一回合（敌方行动结算后清除）。
10. **数值参数集中在 `engine/settings.py`**（新增一节），内容数值（unlock_fam/效果强度）放 content 数据里。

### D3. 修炼效率 helper（供 game 与 smoke 共用，消除重复）
`engine/game.py` 顶层函数（或 state.Player 方法，选一处并在 smoke 里 import 复用）：
```python
def cultivation_mult(p) -> float:
    perm = sum(G.GONGFA[g].permanent_bonus for g, f in p.familiarity.items()
               if f >= S.FAM_ENTRY and g in G.GONGFA and G.GONGFA[g].permanent_bonus)

    if p.main_gongfa is not None and p.main_gongfa in G.GONGFA:

    return p.root_mult * (1 + perm) * main
```

## F. 战斗技能池与 utility 效果（engine/battle.py、engine/game.py）

### F1. 技能池算法（game._battle_skill_pool 重写）
```
def combat_skills(p) -> 技能对象列表（按 id 排序去重）:
    # 1) free 独立术法：恒入池（unlock_fam=0）；kind ∈ attack/defense，或 utility 且 utility_effect 非空
    # 2) 运转池功法（主修 → 战斗槽 1..N → 身法槽，去重）逐本：
    #    若 realm < tier 或 familiarity < FAM_ENTRY：跳过（保险，正常不会在池）
    #    对本功法 skill_ids 每个技能：
    #      requirement=free → 已在 1) 处理，跳过
    #      familiarity < unlock_fam → 跳过（未参悟解锁，不亮）
    #      kind 不可战（utility 且无 effect）→ 跳过
    #      gentle → 入池（遍历池内每本母功法都会走到，天然满足"任一母功法在池"）
    #      strict → 仅当 该 gid 是 p.main_gongfa 或 familiarity ≥ FAM_MAX 才入池
```
结果供 Battle 展示/施放；**技能数量少，P3 不做 12 格编组**（Battle 直接收全量）。

### F2. Battle 记录使用（familiarity 战斗成长）
Battle 增加 `used: set[int]`：玩家每次成功施放技能（skill 动作命中且扣除灵气）记录 sk.id。`Game._finish_battle` 结算末尾：对该技能每个**在运转池的母功法** `familiarity[gid] += FAMILIARITY_PER_USE`（封顶 FAM_MAX）；胜/负/逃都结算（用过了就涨）。文案可不细报。

### F3. utility 效果实现（battle.do 的 skill 分支扩展）
- kind=utility 且 utility_effect 非空才允许施放（否则维持"暂无法施展"拒绝）。
- 施放立即效果/标记：
  - breath：`qi += 建议量级`（如 3×qi_regen，封顶 qi_max），文案"吐纳调息，灵气 +X"。
  - root / weaken / evade：置敌方/自身 flag（`enemy_rooted` / `enemy_weakened` / `self_evading`），文案说明。
- 敌方行动段按 flag 结算：root→跳过（"被缚，动弹不得"）；weaken→dmg×0.5；evade→先 `rng.chance(0.5)` 判定落空（"身形飘忽，堪堪避开"）。敌方行动后清 flag（每回合由玩家动作重新设置）。
- defense 类技能保持 = guard（与"防御"等效的现状不变，不差异化）。
