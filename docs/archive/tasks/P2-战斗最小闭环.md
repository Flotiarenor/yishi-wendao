## 规格

### A. 玩家战斗属性（派生，不新增存档字段）

Player 不存攻防血——每次战斗从 境界档+主修功法 派生临时战力（放 `engine/settings.py` 或 battle 内 helper，占位可标定）：
```python
def battle_stats(realm_idx, qi_max_base=0):
    hp     = 60 + realm_idx*25
    attack = 8 + realm_idx*4
    defense= 4 + realm_idx*3
    speed  = 8 + realm_idx
    return dict(hp=hp, attack=attack, defense=defense, speed=speed)
```
灵气池：`qi_max = 50 + realm_idx*15`；回合自动回 `qi_regen = 5 + realm_idx`；聚气指令：本回合放弃出手，回复 `3×qi_regen`。

### B. 追加 2 个 free 基础技能（content/skills.py）

P1 只有御风术(utility/free)。战斗需要人人可用的基础攻击/防御，**在 skills.py 追加**（不改已有 id）：
- `make_id(CAT_SKILL, 14)` 灵力冲击（无/attack/free/qi_cost 4/power 14）——基础攻击
- `make_id(CAT_SKILL, 15)` 护体灵光（无/defense/free/qi_cost 4/power 0）——基础减伤
照该文件常量命名风格补常量（如 LINGLI_CHONGJI / HUTI_LINGGUANG）。

### C. content/enemies.py（60 段）

仿 sites.py 结构。Enemy 字段（frozen dataclass）：
- `id: int`、`name: str`
- `site_id: int`（归属探索点地点 id，引用 ST 常量——**用 site_id 归属而非改 sites.py**）
- `realm_idx: int`（境界档参照）
- `element: str`（五行，克制用）

示例 ≥8 只，按地点递进：灵脉山 2（练气初期妖兽）、幽谷 2、古战场 2、上古洞府 2，境界档与 site.realm_req 匹配。

### D. engine/battle.py（新文件，纯逻辑状态机）

**架构要点：战斗是多回合会话，与 game.step 单动作分离；rng 复用 game 的 rng（随机流一致可回溯）**：

```python
class Battle:
    def __init__(self, player_stats: dict, player_skills: list[Skill],
                 enemy: Enemy, rng: Rng, ...):
        ...
    def view(self) -> str          # 当前状态文本（双方 HP/灵气/敌信息）
    def available_skills(self) -> list   # 主修功法技能 + 2 个 free 基础术法
    def do(self, action: str, skill_id=None) -> Result
        # 每回合: 玩家动作结算 → (敌存活则)敌人行动 → 检查结束
        # 返回文本 + 战斗是否结束 + 结局(win/lose/fled/None)
```

- 动作集：`attack`(平砍物理) / `skill <skill_id>`(耗灵气、五行克制) / `defend`(本回合受伤减半) / `flee`(成功率=0.5+(玩家speed-敌speed)*0.02，clamp[0.2,0.9]；成功=已逃，失败=敌方白打一回合) / `gather`(聚气)。
- 五行克制（本任务只做"克"环）：
  ```python
  KE = {"金":"木","木":"土","土":"水","水":"火","火":"金"}
  # 攻克守 ×1.5；守克攻 ×0.5；同/无 ×1.0
  ```
  "生"与威力层留 P5。
- 伤害公式（占位）：
  ```
  玩家技能: dmg = power + attack*0.5 - enemy.defense*0.3，×五行系数，±10% rng
  平砍:     dmg = attack - enemy.defense*0.4 ±10% rng（最低 1）
  敌人攻击: dmg = enemy.attack*0.6 - defense*0.3 ±10% rng
  ```
- 结局结算由 game 层负责：
  - **胜**：掉落灵石 loot_stones 入账 + 按 loot_pills 概率掉丹药（进背包）
  - **败（重伤，不致死）**：`p.exp *= 0.5`；折寿 rng 1~5；心魔 +10；编年史"败于【敌名】，重伤遁走"
  - **逃**：无掉落，正常回探索结果

### E. game 层集成（engine/game.py）

- `Game.start_battle(enemy_id) -> Result`：构造 Battle，存 `self._active_battle`，返回欢迎文本+可用技能列表。
- `Game.battle_action(action, skill_id=None) -> Result`：调 battle.do；战斗结束则结算并清空 `_active_battle`。
- **存档规则**：`_active_battle` 是运行时状态**不入存档**。战斗不跨存档：checkpoint/存档点在进战斗前；若玩家中断，按"逃遁失败=重伤结算"处理或直接放弃战斗回战斗前节点（读档即回）。
- step 增加 `"battle_action"`；`_explore` 把现有"危险判定=概率折寿"改为 **遇敌率**：危险命中 → 从该地敌人池（site_id 匹配）抽一只 → `start_battle` → 返回"遇敌！输入战斗指令…"。
- 战斗中死亡保护：本任务重伤不致死，保证不会探索即死。

### F. CLI 战斗界面（cli/main.py）

进入战斗后子循环（复用 auto/管道输入模型），命令前缀 `ba`：
```
【遭遇】你(HP 95/95 灵气 65/65) vs 火狼(HP 40)
1 平砍  2 技能(列可用)  3 防御  4 遁走  5 聚气
ba 1 / ba skill 烈焰斩 / ba 4 ...
```
- auto 模式 bot 简单策略：有克制技能放技能、否则平砍；自己 HP<30% 遁走。
- 战斗结束自动回主循环。
