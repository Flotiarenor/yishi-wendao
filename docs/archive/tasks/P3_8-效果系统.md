## 目标

把散落在 `Battle.do()` 里的硬编码效果（`guard`/`enemy_rooted`/`enemy_weakened`/`self_evading`
四个 bool flag + `_cast_utility()` 的 if-elif）替换为**效果实体 + 固定管线 + 修饰器扩展点**：

- `content/effects.py`：效果模板（纯数据，5 个：root/weaken/evade/guard/breath）
- `engine/effects.py`：`EffectInstance`/`EffectBag`/`resolve_damage`/修饰器与效果注册表
- `engine/battle.py`：改为按管线驱动；对外 API 与属性**完全不变**
- `content/skills.py`：`utility_effect` → `effect_key`，新增 `modifiers: dict`
- 新增 `tests/test_effects.py`（≥25 项）

**明确不做**（写出来即设计过重，见架构文档 §二）：通用 ECS/实体查询、事件总线、效果 DSL、
每个效果一个类、物理/移动/碰撞、召唤物/地形/链式目标、任何新内容或数值调整。

**预算**：`engine/effects.py` ≤ 220 行、`content/effects.py` ≤ 100 行。

## 规格

### A. `content/effects.py`（新，纯数据）

```python
@dataclass(frozen=True)
class EffectTemplate:
    key: str; name: str
    tags: tuple = ()
    duration: int = 1            # 0 = 立即生效不入袋
    max_stacks: int = 1
    stack_rule: str = "refresh"  # refresh / stack / ignore
    apply_key: str = ""          # 立即结算函数键（duration=0 必填）
    tick_key: str = ""           # 每回合结算函数键
    params: dict = field(default_factory=dict)
    desc: str = ""
```

模板（**键名不可改**，现有数据引用它们）：

| key | name | duration | params | 说明 |
|---|---|---|---|---|
| `root` | 定身 | 1 | — | 敌方本回合跳过行动 |
| `weaken` | 破势 | 1 | `{"mult": 0.5}` | 敌方本回合伤害 ×mult |
| `evade` | 闪避 | 1 | `{"chance": 0.5}` | 敌方本回合攻击概率落空 |
| `guard` | 护体 | 1 | `{"mult": 0.5}` | 自身本回合受创 ×mult |
| `breath` | 吐纳 | 0 | `{"regen_mult": 3}` | 立即回灵（apply_key="restore_qi"） |

另导出：`EFFECTS`（key→模板）、`by_key(key)`、`register_effect(template)`、
`EFFECT_LABELS`（key→name，供 UI/兼容）。

### B. `engine/effects.py`（新，运行时 + 管线）

```python
@dataclass
class EffectInstance:
    key: str; source: str = "player"; stacks: int = 1
    duration: int = 1; params: dict = field(default_factory=dict)
    def to_dict(self) -> dict
    @classmethod from_dict(cls, d) -> "EffectInstance"

class EffectBag:
    def apply(self, key, source="player", stacks=1, duration=None, params=None) -> EffectInstance | None
        # duration>0 才入袋；按模板 stack_rule 处理 refresh/stack/ignore
    def has(self, key) -> bool
    def get(self, key) -> EffectInstance | None
    def remove(self, key) -> bool
    def tick(self) -> list        # duration-1；≤0 移除；返回到期 key 列表
    def to_list(self) -> list
    def clear(self)

# 立即结算注册表（duration=0 的效果）
APPLY_FX: dict[str, Callable[[ctx, EffectInstance], list]]   # 内置 "restore_qi"
TICK_FX: dict[str, Callable[[ctx, EffectInstance], list]]    # 预留；本阶段无内置

# 修饰器
MODIFIER_ORDER = ("armor_pen", "extra_dmg")
MODIFIERS: dict[str, Callable[[ctx, float, object], float]]
def register_modifier(key, fn)     # 追加到 MODIFIER_ORDER 末尾
def register_effect(template)      # 追加模板（生成器/测试用）

@dataclass
class DamageCtx:
    base: float = 0.0
    attack: float = 0.0; attack_ratio: float = 0.0
    defense: float = 0.0; defense_ratio: float = 0.0
    element_mult: float = 1.0
    jitter: float = 1.0
    modifiers: dict = field(default_factory=dict)

def resolve_damage(ctx) -> int    # 见架构文档 §四，无修饰器时与现状公式逐位一致
```

内置修饰器语义：
- `armor_pen(params∈[0,1])`：`v += ctx.defense * ctx.defense_ratio * params`
- `extra_dmg(params 数值)`：`v += params`

### C. `content/skills.py`

- 字段 `utility_effect: str` → **`effect_key: str = ""`**（语义扩展：任何 kind 都可用；空=无效果）
- 新增 `modifiers: dict = field(default_factory=dict)`（修饰器键→参数）
- 更新 6 处现有数据：青藤缠/冰缚术→`effect_key="root"`；地陷术→`"weaken"`；
  御风术/凌虚步→`"evade"`；吐纳术→`"breath"`（**键名/数值一律不改**）
- 防御类技能（护体灵光/玄水护身/厚土甲/金钟护体/青木回春/石肤甲）**数据不变**：
  它们在战斗里等价于 `guard`（由管线按 kind=="defense" 施加），不需要 effect_key

### D. `engine/battle.py`（改造，外部 API 不变）

1. `__init__` 增 `self.p_bag = EffectBag()`、`self.e_bag = EffectBag()`
2. 删除四个 flag 的读写；**保留同名只读 property**（派生自效果袋，标注 deprecated 兼容）：
   `guard`/`enemy_rooted`/`enemy_weakened`/`self_evading`
3. `do()` 按架构文档 §四管线改写；**无效指令不推进回合、不产生副作用**的现状保持不变
4. `_cast_utility()` 删除，改由 `effect_key` + 管线施加
5. `UTIL_EFFECT_LABELS` 保留（由 `content.effects.EFFECT_LABELS` 生成）
6. 新增 `effects_data() -> {"player": [...], "enemy": [...]}`（供战报）
7. `do()` 返回值、`last_reason`、`used`、`available_skills()`、`ke()`、`view()`、`p_*`/`e_*` 不变

### E. `engine/game.py`

- `combat_skills()`：`sk.utility_effect` → `sk.effect_key`（判定"utility 须有效果"）
