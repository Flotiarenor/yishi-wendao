# 文档地图（docs/）

> 目的：一页看清**每份文档管什么、谁说了算、还算不算数**。
>
> ## ⚠️ 读文档前必读（2026-09-10 统一口径）
>
> 1. **"现状是什么样"只有一个事实源：根 `README.md` 的「当前状态」事实表。**
>    测试项数 / smoke 指纹 / 世界指纹 / 栅格 / 视野 / 性能等数字**只在那一处维护**。
> 2. `docs/` 下所有文档里的数字（测试项数、指纹、格宽、视野半径、性能）一律是**当时快照**，
>    **不作为现状依据**。它们记录的是"当时做了什么、为什么"，价值在理由而不在数字。
> 3. **发现文档与代码冲突 → 以代码 + 根 README 事实表为准**，改文档前先跑一次基线
>    （`.venv\Scripts\python.exe -X utf8 main.py test`）。
> 4. **新增文档时不要再复制数字**——写"见根 README 事实表"。
>    数字被复制的次数 = 将来被误导的次数（本次统一口径就是因为这个）。
> 5. 新会话入口顺序：根 `README.md`「当前状态」→ 本文件 → `设计定案.md`（规则）→
>    `实现路线图.md`（进度与顺序）→ 当前阶段任务书。
